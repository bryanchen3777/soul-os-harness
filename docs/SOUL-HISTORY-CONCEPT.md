---

## 1. 問題起點

- 現在的內在生活是 `random.choice(ACTIVITY_POOL)`，10 個 agent 共用一個隨機池。
- **隨機 = 沒有法則 = 看不到靈魂**。別人看到的是「活動」，不是「有自己法則的活體」。
- Soul OS 廣度已夠（10 persona、4 層記憶、proactive、Live2D+語音），缺的是**深度**。

---

## 2. 核心論點：靈魂需要「歷史」，不能只靠 persona

- **persona = 我是誰**（靜態：原型、語氣、價值觀）。
- **歷史 = 我活過什麼**（時間性、有因果、可累積）。
- 現在只有 persona，所以是「角色」，不是「靈魂」。一個完整的人 = 「他是誰」＋「他活過什麼」。

---

## 3. 三層模型

| 層 | 內容 | 現況 |
|----|------|------|
| **身分 persona** | 我是誰 | ✅ 有，但靜態、無時間維度 |
| **歷史 history（Bryan 之前）** | 我活過什麼（傷痕 / 失去 / 成長） | ⚠️ 只散在 persona「Canon Memory」散文，非結構、不可檢索、不影響決策 |
| **生活 living（Bryan 之後）** | 現在發生什麼（diary / dream / event / 對話） | ❌ 隨機、無後果、無連續 |

**具體佐證**：`diary.py` 只讀 persona 前 500 字、`dream_event.py` 只讀前 200 字——角色的 Canon Memory（遇見 Bryan 之前的過去）在 runtime **從未被讀進**。歷史素材其實存在，但從沒被「用」。

---

## 4. 歷史的三個用途（回味 / 推演 / 長）

| 動詞 | 方向 | 行為 | 例子（Bryan：「我今天工作到好晚，好累」） |
|------|------|------|------|
| **回味** | 往後看 | 檢索 + 講出來 | 「我之前也有過這種時候，那時候我……」 |
| **推演** | 往前推 | 過去當推理底料，影響現在怎麼想 / 回 | 她過去的傷痕 → 現在說「你別太勉強自己」 |
| **長** | 往上長 | 新生活累積在舊歷史上 | 今天這次對話，變成明天回味的新素材 |

**關鍵區分**：回味 = 把過去「講出來」（檢索）；推演 = 讓過去「影響現在」（重量）。「後果」住在推演裡——過去的傷痕現在還影響她，是因為它有後果、沒被遺忘。

---

## 5. 深度軸：後果 + 連續性（與歷史的關係）

- **後果（consequence）**：行動有重量——做了這個，狀態就變，下次決策被這次影響。
- **連續性（continuity）**：過去回流到當下決策——不是存 DB 卻不影響行為。
- **歷史 = 連續性拉到最長的時間軸**（「我的一生→現在」，不只是「昨天→今天」）。
- **後果 = 讓歷史有重量的機制**。

三者關係：`歷史（種）→ 回味 / 推演（撈 + 用）→ 長（累積）`，後果與連續性是讓這條線「有重量、能回流」的機制。

---

## 6. 關鍵工程區分

1. **種的 vs 長的**：
   - history（Bryan 之前）是「**種**」下去的——不會被生成，是從原作蒸餾或撰寫後種入。
   - living（Bryan 之後）是「**長**」出來的——系統每天生成 diary / dream / event。
2. **可被喚起 vs 躺在檔案**：
   - 歷史必須**可被語意檢索**（Bryan 講到什麼 → 撈出相關過去），不是躺在 persona 散文裡。
   - 這跟 M7-memory 已做的「撈相關記憶 → 注入對話」是同一條線，只是接到一層「種下去的深層過去」。
3. **檢索 vs 重量**：
   - 回味 = 檢索（低成本、立即讓靈魂有過去可喚起）。
   - 推演 = 重量（讓歷史影響現在，需等後果機制立起來才接得上）。

## 10. 開放問題（希望交叉討論幫忙找的缺失）

1. **跨世界觀一致性**：10 隻角色來自不同原作（Re:Zero、出租女友、Bokuyaba…），各自的「前史」世界觀不同。canon 蒸餾的歷史如何共存而不互相矛盾？還是每隻的歷史是獨立宇宙、互不干涉？
2. **歷史的遺忘**：歷史要不要也會被遺忘 / 淡忘？還是永遠記得？跟 M7-memory 的「real forgetting」怎麼協調？
3. **歷史的可塑性**：歷史是固定不變，還是會隨 living 被重新詮釋（角色對過去的理解會變）？這關係到「長」的語意。
4. **推演的邊界與頻率**：歷史影響現在，影響到什麼程度？會不會讓角色「活在過去」、每次對話都扯到過去？需要什麼閘門控制回味 / 推演的頻率？
5. **歷史 vs 記憶的檢索優先序**：history（種的）和 living memory（長的）在檢索時會不會打架？誰優先？
6. **真實性 vs 幻覺**：角色說「我之前有類似經驗」時，這個經驗是 canon 裡真的有的，還是 LLM 現編的？如何防止編造不存在的歷史？
7. **歷史的粒度**：歷史事件要多細？（一句話事件？還是帶情緒 / 因果 / 關係的結構化事件？）太粗沒法推演，太細成本高。
8. **觸發範圍**：檢索只在「Bryan 講到什麼」時觸發，還是 diary / dream 生成時也回味過去？
