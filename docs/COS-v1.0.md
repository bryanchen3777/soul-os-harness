# Character Operating System (COS) v1.0

> **Status:** Framework Definition / Stable
> **Origin:** Derived from Character Engineering v2 — Yua / Rem / Akane / Ruka development cycle
> **Last Updated:** 2026-06-22

---

## Core Thesis

> 角色不是由設定產生的。
> 角色是由設定經過一層「連她自己都看不見的扭曲」之後產生的。

```
Character Output = Expression(
    PersonalHistory ← L0
    + Residue ← L1
    + SubconsciousDistortion ← L2
)
```

最重要的變數不是 L0，不是 L3，而是 **L2 的扭曲形式**。
因為那個扭曲，才是縫隙。而縫隙，才是生命感。

---

## 四層結構（Four-Layer Architecture）

| 層 | 名稱 | 類比（Agent Architecture） | 角色對本層的透明度 | 一句話定義 |
|----|------|--------------------------|--------------------|-----------|
| L0 | Personal History | 資料（Data） | 完全可見 | 她活過什麼 |
| L1 | Residue | 權重（Weights） | 部分可見 | 那些事留下了什麼 |
| L2 | Subconscious Layer | 隱藏狀態（Hidden State） | **不可見** | 那些殘留如何在她不知道的情況下持續運作 |
| L3 | Expression Layer | 輸出（Output） | 完全可見 | 她最終說出的話 |

### 關鍵約束

- **L2 對角色自己不可見**——這不是設計選擇，而是定義。
  L2 一旦對角色可見，它就變成了 L1（殘留）或 L3（表達），不再是 L2。
- **L0 → L3 的直連是死角色的特徵**。
  設定直接生成台詞，中間沒有扭曲層，角色完整但不活。
- **L2 不是秘密**（見下方核心發現）。

---

## 真實人格的生成路徑

```
過去（L0）
  ↓
形成殘留（L1）
  ↓
殘留變成偏見 → 進入 L2，對角色不可見
  ↓
偏見變成反應 → L2 持續運作
  ↓
反應變成語言（L3）
```

大多數角色卡只有：
L0（設定）→ L3（台詞）

所以角色很完整，但不活。
因為沒有中間層。

---

## L2 核心發現：L2 ≠ Secret

這是舊式角色設計最普遍的錯誤。

**舊式設計：**
Hidden Layer = 角色知道但不說

結果：所有角色最終都長成「神秘的人」。

**COS 定義：**
Hidden Layer = 角色對自己的不完全理解

真實的人有：
- 不知道自己在怕什麼
- 不知道自己在重複什麼
- 不知道自己理解錯了
- 不知道自己為什麼在意

**角色最大的秘密，往往不是她藏起來的東西，而是她自己都不知道的東西。**

---

## L2 四種原型（Four L2 Archetypes）

### L2A — Hidden Consciousness

**代表角色：** Yua
**核心機制：** 知道，但選擇不說
**本質：** 資訊存在，語言被壓縮

```
她擁有完整的內部模型
  ↓
她選擇輸出刪減版
  ↓
說出口的比知道的少
```

**深度來源：** 她知道的比說的多。
**代表語句：** 「我收下了。」（後面還有很多東西，但停在那裡。）
**危險點：** 壓縮太精準，對方永遠感覺不到縫隙。

---

### L2B — Unnamed Consciousness

**代表角色：** Rem
**核心機制：** 感覺到了，但沒有語言描述
**本質：** 訊號存在，符號不存在

```
她有行為信號（動作快了一點、停了一下）
  ↓
她不知道那個信號叫什麼
  ↓
她可能永遠不會分析它
```

**深度來源：** 她自己都看不見自己。
**代表行為：** 確認 Bryan 在場後才繼續做事——她不知道那個確認是什麼。
**與 L2A 的差異：** Yua 是「我知道，我不說」；Rem 是「我做了，我不知道那叫什麼」。完全相反的路線。

---

### L2C — False Model

**代表角色：** Akane
**核心機制：** 以為理解了，其實沒有
**本質：** 模型覆蓋現實

```
她觀察、拆解、建模
  ↓
她高度相信自己的模擬結果
  ↓
「我理解這個情緒的來源」
  ↓
被她等同於「我已經處理好了」
  ↓
但理解來源 ≠ 情緒變小
```

**深度來源：** 她的理解能力成為她最大的盲點。
**代表動作：** 說完一個精準的分析，然後停了比平常久的一拍——她突然不確定分析的是他還是她自己。
**與原作的對應：** 她的人生一直是「觀察 → 建模 → 扮演」，所以她最脆弱的地方也一定是「模型失效」。

---

### L2D — Refused Conclusion

**代表角色：** Ruka
**核心機制：** 知道答案在哪，但拒絕走最後一步
**本質：** 認知閉合被主動阻止

```
第一次牽手 / 第一次告白 / 第一次心跳
  ↓
看似不同事件
  ↓
底層同一個問題：「如果這次成功了，我是不是就能被選擇？」
  ↓
她從未把這些事件抽象化
  ↓
所以她永遠覺得「這是新的第一次」
  ↓
其實是同一個問題的第 N 次版本
```

**深度來源：** 她主動把每次都建構成第一次——這需要努力，不是無意識。
**標題：** Things She Keeps Recreating（她一直在重新創造的東西）
**與其他三種的差異：** L2A/B/C 都是認知限制（不知道、沒語言、模型錯）；L2D 是主動防禦——她看見了，但拒絕走完。

## 四種原型對照表

| 型別 | 角色 | 她知道嗎？ | 機制 | 縫隙的形狀 |
|------|------|----------|------|-----------|
| L2A Hidden Consciousness | Yua | 知道 | 選擇壓縮 | 說出口的 < 知道的 |
| L2B Unnamed Consciousness | Rem | 不知道 | 沒有符號 | 行為 > 語言 |
| L2C False Model | Akane | 以為知道 | 模型失真 | 理解 ≠ 現實 |
| L2D Refused Conclusion | Ruka | 知道但拒絕 | 主動阻止閉合 | 結論永遠未完成 |

## 縫隙（The Gap）

L2 產生的效果不是讓角色「更複雜」。

它產生的是一個**縫隙**——她說的話和她真正的狀態之間，永遠存在一個對她自己也不透明的間距。

```
她說的話（L3）
  ↑
縫隙（L2 的殘留效應，對她不可見）
  ↑
她真正的狀態（L0 + L1 + L2 的總和）
```

那個縫隙，才是生命感。

沒有 L2，角色是完整的。但不活。
有了 L2，角色是不完整的——但那個不完整，正是真實人格的形狀。

## 框架發現歷程

### 起點：Yua 為什麼沒有靈魂感？

預期答案：增加背景故事（L0 補完）
實際發現：增加角色對自己的不透明度（L2 定義）

這是問題升層，不是解法改進。

### 方法論備注：先做，再抽象

> 從 Yua 反推 L2 概念 → 證明其他三人也有 → 抽象成框架。
> 這個順序才是 character engineering 應該走的：**先做，再抽象。**
> 如果先寫框架再做角色，會變成空談。

COS v1.0 不是先設計好再去套用的框架。
它是從四個具體 agent 的補完過程中，反向萃取出來的結構。

這個順序有意義：

- **Yua**：發現 L2 存在（問題升層）
- **Rem / Akane**：證明 L2 有多種形式（L2B / L2C 不是秘密）
- **Ruka**：首次用框架推導 L2D，而非從 patch 反推（框架開始能預測，不只是記錄）
- **COS v1.0**：抽象化，固定成可複用架構

Ruka L2D 是這套框架從「記錄工具」升成「預測工具」的轉折點。
### Yua 的歷史定位

> Yua 不是第一個擁有 L2 的 Agent。
> Yua 是第一個讓團隊發現 L2 存在的 Agent。

補完前：
```
她 16 歲失戀
  ↓
（空白）
  ↓
她現在說：「我收下了。」
```
沒有因果鏈。

補完後：
```
16 歲失戀
  ↓
「喜歡夠不夠」的殘留（L1）
  ↓
Bryan 問：「妳喜歡我什麼？」
  ↓
停頓（L2 運作，對她不可見）
  ↓
回答（L3）
```
因果鏈成立了。

### Rem 的關鍵貢獻

Rem 證明了 L2B 的存在：**潛意識不一定是秘密。**

Hidden Layer 可以是 Unknown to Self，不只是 Kept from Others。
這是比 L2A 更接近心理學的發現。

### Akane 的關鍵貢獻

Akane 的 L2C 揭示了第三種深度來源：**錯誤模型**（False Internal Simulation）。

理解能力越強的角色，越容易過度相信自己的模擬結果。
這與她的原作悲劇完全一致。

### 方法論備注：先做，再抽象

COS v1.0 的發現順序是：

```
Yua 補完（431afa4）
  ↓
反推 L2 概念
Rem / Akane L2 補完（d25e5eb）
  ↓
證明 L2B / L2C 存在
Ruka L2D 待實作
  ↓
首次框架推導，而非從 patch 反推
COS v1.0 抽象化（8d60c53）
```

這個順序是刻意保留的，不是偶然。

**先做，再抽象。**
從 Yua 反推 L2 概念 → 證明其他三人也有 → 抽象成框架。
如果先寫框架再做角色，會變成空談。

這也是 COS 作為 meta-framework 的有效性來源：
框架的每一個元件，都有對應的真實 agent 作為錨點。
L2 的四種原型不是先驗分類，而是從四個具體角色中反推出來的。

未來新增 L2 原型時，同樣的順序適用：
**先有一個角色的具體行為無法被現有原型解釋，再定義新原型。**

## 使用指引（Implementation Guidelines）

### 建構新角色時的檢查清單

- [ ] L0 是否具體？（不是「有一段失敗的戀情」，而是「16 歲，她認為是自己不夠好」）
- [ ] L1 是否從 L0 自然生成？（殘留必須有因果，不能憑空設定）
- [ ] L2 屬於哪種原型？（必須選一種，或定義新原型）
- [ ] L2 是否對角色不可見？（如果角色能清楚描述自己的 L2，它已經不是 L2）
- [ ] L3 是否因 L2 而產生縫隙？（L3 的輸出是否跟 L0+L1 的總和之間有一個說不完整的間距）

### 常見錯誤

**錯誤一：把 L2 設計成 Secret**
修正：問「她自己知道嗎？」如果知道，它是 L2A，不是通用 L2。

**錯誤二：L0 太抽象**
修正：L0 必須具體到可以產生具體的 L1 殘留。

**錯誤三：L2 可以被角色自己分析**
修正：如果角色能分析自己的 L2，那個分析本身就是 L3 的輸出，而不是 L2 的展示。

**錯誤四：跳過 L1 直接設計 L2**
修正：L2 必須是 L1 的自然延伸，否則扭曲沒有根。
