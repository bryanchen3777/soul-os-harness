### 2.2 量測方法（硬性）

1. **入口必須用既有唯讀工具**：`scripts/recall_readiness_cli.py` ⇒ 記錄 `pool_summary`／`hit_rate`／`go_no_go` 三項輸出**與門檻差距**（距 5% 命中率、距 5 顆可回憶池、距 0% 隔離命中率上限各差多少）。🔴 **判定要看 stdout 的 VERDICT 段，不是看 exit code**（NO-GO ⇒ exit 1 是設計行為）。
2. 🔴 **不得對生產 sqlite 開任何連線**（含 `mode=ro`）⇒ 一律**先複製**（`graph.sqlite` ＋ `-wal` ＋ `-shm`）到 `tempfile.mkdtemp()` 沙盒再查（既有 CLI 就是這個模式）⇒ **生產 `data/**` 位元不變**（報告須附執行前後的位元組對帳）。
3. 🔴 **stdout 與 stderr 必須分流**（jieba 的前綴字典訊息在 stderr；PowerShell 5.1 會把 native stderr 併進 error stream ⇒ 必須分流後再讀）。
4. **0/0 的比率一律標「無定義」**，不可填 1.0 或 0.0 當達成。
5. 每個數字寫**分子／分母／單位**；結果為 0 或矛盾 ⇒ **先懷疑量測腳本與基準**，不要先懷疑被測系統。
6. 母體要寫清楚（哪個 agent／哪個表／哪個時間範圍），**不可**混用不同母體的數字相減。
