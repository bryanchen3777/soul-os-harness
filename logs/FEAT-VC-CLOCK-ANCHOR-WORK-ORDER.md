## 工單：FEAT-VC-CLOCK-ANCHOR（VC 聊天報時契約：機械式擋截 ＋ 權威時間注入）

- **開立者**：主大腦（Engineering Brain）
- **來源**：Owner 2026-10-28 審定備案「VC 裡的雷姆回答的時間差 3 小時」＋ 裁定「**兩個都做：機械式擋截 ＋ 權威時間注入**」
- **狀態**：開立（decision-complete；執行者照做即可，不需再做設計決策）

---

### 目標

讓 VC（voice companion）聊天裡的代理**不再報出錯誤的時鐘時間**，而且**一旦要報，必須是對的**。

### 做法（決策已定，執行者照做）

#### D1. 機械式擋截（消除「亂報時間」的可能性）

在 `clients/voice_companion/akane_voice_brain.py` 既有輸出守門（`_guarded`）**加入時鐘時間偵測**：

- 偵測「**具體時鐘時間**」：中文數字＋「點」（含「點」「點半」「點…」）、阿拉伯數字＋「點／:」、以及「現在是…點」「今天…點」「明天…點」「星期X…點」等**含時鐘數字的句式**。
- 命中時的處置（依 persona 契約）：**不得把該句原樣輸出** ⇒
  - 優先：**整句剔除**（把含時鐘數字的那一句從輸出拿掉）；
  - 若剔除後輸出為空 ⇒ 走既有 fallback（不得回一句含時鐘數字的替代語）。
  - **🔴 不得**把它改寫成另一個時間數字（那只是把亂報換成亂報）。
- 必須**不得**誤傷這些合法表述：「今天比較晚出現呢」「都這麼晚了還不睡嗎」「下午的光線很舒服」——**只擋含具體時鐘數字的表述**（`X點Y分` / `HH:MM` / 「現在是 3 點」這類）。
- 守門為 **fail-closed**：偵測不到就照原樣輸出（不可因新邏輯而讓正常回答被吃掉）；任何例外 ⇒ 放行原文並記 log。

#### D2. 權威時間注入（讓「萬一要報」時報得對）

在 VC 的 system prompt **新增一個明確區塊**（放在【當前時序體感】之後、歷史之前）：

```
【當前本地時間（權威）】
- 現在是 2026-10-28 11:27（America/New_York ＝ 紐約時間，24 小時制）
- 若要引用時間，只能用上面這個時間；不得自行換算、不得臆測時區。
```

- 時間值**必須**由 `src/timezone_utils` 既有工具取得（`now_local()`／`format_localized()`），**不得**自行組時區字面值、**不得**寫死 offset。
- ⚠️ **不得**讓代理「看到這個區塊就必須報時」——本區塊只是**權威事實**，不是**報時指令**；報不報仍由 persona 的 `expression_mode` 決定（D1 才是那個機關）。

#### D3. 觀測

- 每次擋截時寫一行 log：命中句、命中原因（哪種型態）、最終輸出長度。
- 每次注入時不需 log（避免日誌雜訊）。

### 測試（新增守衛 `tests/clients/test_vc_clock_anchor_guard.py`）

| # | 不變量 | 變異方向（必須轉紅） |
|---|---|---|
| G1 | 含「X點Y分」的句子**被剔除**，且**輸出不含任何時鐘數字** | 把剔除邏輯關掉 ⇒ 必紅 |
| G2 | 含「HH:MM」／「現在是 3 點」的句子同樣被剔除 | 只擋中文數字點、漏掉阿拉伯數字 ⇒ 必紅 |
| G3 | **合法**的模糊時間表述（「今天比較晚出現呢」「都這麼晚了還不睡嗎」「下午的光線很舒服」）**不被剔除** | 把模糊表述也判成違規 ⇒ 必紅 |
| G4 | 剔除後為空 ⇒ 走既有 fallback，且 fallback **不含時鐘數字** | 讓 fallback 回一句含時間的字串 ⇒ 必紅 |
| G5 | 注入的時間區塊**與 `now_local()` 一致**（同一刻取值）且**帶時區鍵** | 讓注入改用 UTC 或去掉時區鍵 ⇒ 必紅 |
| G6 | 注入區塊**不含**「必須報時」之類的指令語句（不得反過來逼代理報時） | 把區塊改成「你必須回答當前時間」⇒ 必紅 |

⇒ 每條都要有**專屬變異實驗**且**必須轉紅**；變異 harness 放 `%TEMP%`（改副本執行），**repo 檔案全程零寫入**（前後 sha256 相同）。**ABORT 與 GREEN 同等嚴重。**
⇒ 守衛**不得呼叫真實 LLM**（用 fake `llm_stream` 注入）⇒ **零成本**。

### 驗收（完成的定義）

1. 用 fake `llm_stream` 餵一句含「一點二十七分」的代理輸出 ⇒ **最終輸出不含任何時鐘數字**。
2. 餵一句合法模糊表述 ⇒ **原樣保留**。
3. VC 的 system prompt 含【當前本地時間（權威）】區塊，且其值與 `now_local()` 同刻一致、帶 `America/New_York`。
4. 守衛 G1～G6 全綠，六條變異各自精準轉紅（repo 零寫入）。
5. **定向測試全綠**，且既有 VC 相關測試（如 `tests/clients/**`）維持全綠。

### 回報格式

1. 改動檔案清單（逐檔：改了什麼、為什麼）。
2. 守衛 G1～G6 的「變異內容 → 哪條轉紅 → repo sha256 前後相同」證據。
3. **機械式擋截的行為證據**：餵「一點二十七分」前後的輸出對照（剔除前後）；餵合法模糊表述的前後對照。
4. **權威注入的實測值**：注入區塊原文 ＋ 與 `now_local()` 的同刻一致性證明。
5. 定向測試結果（命令、passed/failed/skipped、exit code、**註明解譯器＝repo `.venv`**）。
6. 是否曾誤傷合法表述（若曾，說明如何收斂）。
